# M3-rag — Embedding Pipeline for RAG

Учебный проект: полный retrieval pipeline ingest → embed → query на документации.

## How to run

```bash
python chunker/chunker.py    # step 1: chunk docs → chunks.jsonl
python embedder.py           # step 2: embed + save to Postgres
```

Chunker reads `docs/project-data/**/*.md`, classifies by doc_type, and writes `chunks.jsonl`.
Embedder reads `chunks.jsonl`, calls Ollama for embeddings, writes `chunks_embedded.jsonl`, and saves to Postgres.

## Prerequisites (MUST be running first)
- **Ollama** on `localhost:11434` with `bge-m3` model: `ollama pull bge-m3`
- **PostgreSQL with pgvector** on port `35432` (Docker: `pgvector/pgvector:pg17`)
- `.env` with `DATABASE_URL=postgresql://user:pass@localhost:5432/dbname`

## Key files
- `chunker/chunker.py` — Markdown parser, doc_type classifier, chunk builder
- `chunker/tests/test_chunker.py` — all tests: `pytest -q chunker/tests/`
- `embedder.py` — Ollama embedding batcher + Postgres pgvector writer
- `chunks.jsonl` — required input for embedder; do not edit manually
- `chunks_embedded.jsonl` / `.embed_progress.json` — generated by embedder; safe to delete

## Architecture notes
- Chunker is stdlib-only (no pip install). Embedder uses `psycopg2` (`pip install psycopg2-binary`).
- Postgres table: `rag_chunks` with `VECTOR(1024)` column + HNSW index.
- Embedder is resumable via `.embed_progress.json`; auto-cleans on success.
- Doc types: `adr`, `api_endpoint`, `feature`, `generic`, `glossary`, `incident`, `page`, `runbook`.
